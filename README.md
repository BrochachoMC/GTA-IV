## ℹ️ About the Project

This project was created as a learning experience. Since I don't know how to program yet, I used **Claude** to help me develop the APK.

The app is extremely simple: its only purpose is to play an `.mp4` video containing an edited version of the **Grand Theft Auto VI** introduction, with intentionally added glitches for the prank.

The APK does not collect data, install additional software, or perform any other actions beyond what is described above.

## 📦 Contents

- Android application
- One `.mp4` video file
- Fullscreen video playback
- The app closes after the video finishes
